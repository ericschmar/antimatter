# Keyboard Shortcuts

- `⌘K`: command palette.
- `Return`: send composer content when mention completion is closed.
- `Shift-Return`: newline.
- Mention list: `↑`/`↓` selection, `Return`/`Tab` accepts, `Escape` dismisses.
- Workspace commands to define in the native menu: focus composer, close active tab, split right, split down, attach file, attach image, open emoji picker, settings.

Use macOS-standard shortcuts where unambiguous. Expose all commands in the menu bar and validate them against selected pane/editor state.
